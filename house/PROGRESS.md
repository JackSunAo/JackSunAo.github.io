## 环境要点（每次续跑先做）

- Blender Python：`python3 -m venv $SCRATCH/venv && $SCRATCH/venv/bin/pip install bpy==4.2.0`（需要 Python 3.11；scratchpad 会随容器重置而丢失，丢了就重装）
- 资源下载缓存：`house/assets/`（不进 git，`model/assets.py` 会自动重新下载 Poly Haven 资源）
- 渲染只有 4 核 CPU：预览用 `--preview`，高清图放后台跑
- 自动续跑：每 2 小时一次的定时提醒（Routine 名“湖景豪宅建模续跑”），全部完成后删除

## 已定的设计决策

- 前院：照 AI 图——鲸舌龙舌兰、黄杨弧形绿篱、锥形冬青、粉黛乱子草、细茎针茅、门两侧荷花玉兰
- ① 规则式花园：经典玫瑰园（粉/红/白玫瑰 + 薰衣草镶边 + 绣球），黄杨围边，喷泉
- ② 紫藤廊架：美国紫藤
- ③ 宿根花境：德州山地自然风——秋鼠尾草、墨西哥鼠尾草、松果菊、金光菊、猫薄荷前排、俄罗斯鼠尾草后排、德州银叶灌木、粉黛乱子草点缀
- ④ 睡莲池：自然风——睡莲、路易斯安那鸢尾、蕨类、垂柳
- ⑤⑥ 菜园 / 果园：法式菜园混种；桃、无花果、盆栽柠檬；树下蓝帽花 + 印第安画笔
- 活动草坪：结缕草；活橡树 + 秋千；紫薇（白 + 淡紫）；德州紫荆；车轮梅 + 矮生代茶冬青做骨架
- 湖岸：落羽杉 + 柳枝稷；野花草地用金鸡菊/天人菊
- 模型来源：混合方案——Poly Haven 扫描模型（树、灌木、草、家具），德州特有品种程序化生成
- 天空：黄昏用 Poly Haven `syferfontein_0d_clear_puresky` + 低角度暖色夕照（DuskSun），白天用 `kloofendal_48d_partly_cloudy_puresky`；室内镜头用白天 HDRI + 室内补光（inside 模式）
