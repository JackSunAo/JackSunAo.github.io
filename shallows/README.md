# Coastal Shallows · 海岸浅滩实时模拟

单文件 Three.js 页面：`index.html`（约 0.8 MB，内含 three.js 与全部着色器，无任何外部请求，可直接双击在 `file://` 下打开）。
源码在 `src/`，用 `npm i && npm run build` 重新生成 `index.html`。

## 来源与许可

- 灵感与功能清单来自 [hajimetwi3/hajimetwi3-prompt-okiba](https://github.com/hajimetwi3/hajimetwi3-prompt-okiba) 的
  `contents/demo/realtime_kaigan_subagent.txt`（MIT License，Copyright (c) 2026 Hajime Tsui）。该仓库只有一份**制作依赖提示词**，没有代码；
  这里的代码是按照提示词的要求**独立实现**的，没有复制其中任何程序代码。
- 运行时依赖：[three.js](https://github.com/mrdoob/three.js)（MIT），打包进 `index.html`。
- 无外部图片 / 模型 / 字体；所有纹理都在运行时程序生成。

## 实际采用的方案

| 内容 | 做法 |
| --- | --- |
| 共享海岸数据 | 一个解析的高度函数 `groundHeight(x,z)`（`src/world.js`）同时生成地形网格、1024² 高度纹理、波场求解和相机碰撞。沙滩、沙坝、海岬都来自它 |
| 沿岸/离岸波浪 | 3 列涌浪（周期 5.6 / 7.8 / 10.6 s）+ 14 个风浪分量（λ≈0.35–7 m）。**不是** FFT |
| 浅水化与折射 | `src/waves.js` 在 CPU 上逐列从深水推进到岸边：色散关系 `ω²=gk·tanh(kd)` 求 k(d)，相位 Φ=∫ky dz（波峰线随水深弯曲），Green 定律（群速度）+ 折射系数决定波高。结果存成 3 张 512² 浮点纹理 |
| 碎波判定 | 深度限制：`2A > γd`（γ≈0.8，沿岸带噪声）即碎波，之后波高被压到 0.27d 并带有“湍流记忆”，沙坝之间可重新成形 |
| 遡上 / 引き波 | 相位继续延伸到陆地（水深下限 0.12 m），水位 `η>地面` 的地方才有水膜；水膜厚度控制透明度，退潮时 η 下降形成引き波；岸上的涌水边缘不是贴图 |
| 泡沫历史 | 1024×768 浮点纹理逐帧模拟：在碎波波峰和涌水前沿生成，沿波浪流速（轨道速度 + 碎波前进速度 + 退水沿坡下流）半拉格朗日平流、扩散、按水/陆不同时间常数衰减，因此会留在沙上并在引き波中拉长 |
| 湿沙 / 干燥 | 同一张纹理的另一通道记录“最大遡上历史”，按空间不均匀的时间慢慢变干；湿沙变暗、饱和度提高、粗糙度降低并反射天空/太阳 |
| 水面材质 | 解析法线、Fresnel、云与天空反射（含程序云）、GGX 太阳闪光、沿折射光线对**真实高度纹理**做光线步进（得到真实水深路径，按 RGB 吸收 + 体积散射）、距离粗糙度与水平线抗锯齿 |
| 焦散 | 解析式：用风浪分量的法线折射太阳光线，对水面→海底映射求雅可比行列式取 1/|J|，因此焦散随表面波动、太阳方向和水深变化，不是贴图平移 |
| 水下 | 水面从下方渲染（Snell 窗口、全反射、海底倒影、水面泡沫）；水体雾为逐通道吸收+散射；悬浮颗粒；穿越水面时平滑过渡并在镜头上留下水滴 |
| 生物 | 6 群小鱼（顶点着色器里游动，通过水面看到时按水深吸收变淡）、海鸥（滑翔/振翅）、海岸草（风摆） |
| SSR | **未采用**：水面用解析天空/云反射，岬角倒影缺失，换来没有屏幕边缘缺失和时序闪烁 |

事先生成 vs. 运行时：高度纹理与三张波场纹理在启动时（以及改变潮位/波高/波向/上溯滑条时，90 ms 防抖）由 JS 生成；波的时间演化、泡沫/湿沙模拟、焦散、水面与天空全部在 GPU 每帧计算。

## 画质与设备

`Low / Medium / High / Ultra`（设置里可选，默认“自动”：桌面 High，触屏 Medium，帧率持续低于 26 fps 会自动降一档）。画质影响渲染分辨率、MSAA、水面与地形网格密度、海底光线步进步数、焦散迭代、草和鱼的数量；浅水化、碎波、波打际、湿沙、水下、水面穿越、UI 与“只显示景观”在所有档位都保留。

## 操作

`1–0` 切换视角 · 拖动环视 · 滚轮缩放 · `E` 探索（WASD、Shift 加速、Space 上浮、C 下潜、R 回到出发点；触屏有摇杆和上浮/下潜按钮）· `Space`/`P` 暂停 · `H` 或右上角图标“只显示景观”（`Esc` 或三指轻点恢复，恢复后回到原来的面板/焦点状态）· `F` 全屏。

## 已验证与未验证

- 在无 GPU 的软件渲染（SwiftShader）里验证过：着色器编译/链接无错误、控制台无错误/警告、10 个视角都能出图、水下与水面穿越、隐藏/恢复界面、移动端 390×844 布局。
- **没有在真实 GPU 上测过帧率**，因此不给出帧率保证；软件渲染下的帧率没有参考意义。
- 已知限制：高度场水面无法形成真正卷曲的“管浪”（波前靠非对称剖面 + 泡沫表现）；没有浪花飞沫粒子；没有阴影；天空是程序云，不是完整大气散射；水面反射里没有岬角/岩石。

## 免责声明

本作品是视觉模拟。“可游泳”只表示画面上的平缓、清澈的海滩气氛，**不代表任何真实海岸或海况的安全性**；下水前请查看当地天气、警报、救生员与管理方的指引。
